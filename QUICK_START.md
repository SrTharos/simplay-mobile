# ⚡ Quick Start - SimPlay Mobile

Comece a usar o SimPlay Mobile em 5 minutos!

## 📱 Instalação Rápida

### Android
```bash
cd simplay-mobile
pnpm install
pnpm android
```

### iOS
```bash
cd simplay-mobile
pnpm install
pnpm ios
```

### Web (Desenvolvimento)
```bash
cd simplay-mobile
pnpm install
pnpm dev
```

## 🎵 Seus Primeiros 5 Minutos

### 1️⃣ Adicionar Músicas (1 min)
```
Menu → "Adicionar Músicas" → Selecione arquivos → Pronto!
```

### 2️⃣ Reproduzir Música (30 seg)
```
Playlist → Toque em uma música → Player abre automaticamente
```

### 3️⃣ Controlar Reprodução (1 min)
```
⏯️ Play/Pause
⏭️ Próxima
⏮️ Anterior
🔀 Shuffle (aleatório)
🔁 Loop (repetir)
```

### 4️⃣ Marcar Favorito (30 seg)
```
Playlist → Toque no ❤️ → Música marcada como favorita
```

### 5️⃣ Ver Estatísticas (1 min)
```
Estatísticas → Veja Top 5 do Mês e Top 10 do Ano
```

## 🎯 Tarefas Comuns

### Adicionar Múltiplas Músicas
1. Menu → "Adicionar Músicas"
2. Selecione várias músicas (toque em cada uma)
3. Clique em "Adicionar" ou "Confirmar"

### Remover Música
1. Playlist → Encontre a música
2. Clique no botão 🗑️ (lixo)
3. Confirmação aparece → Clique "Sim"

### Mudar Velocidade
1. Player → Seção "Velocidade"
2. Escolha: 0.5x, 0.75x, 1x, 1.25x, 1.5x, 1.75x, 2x

### Sincronizar Letras
1. Player → "Adicionar Letras"
2. Cole a letra completa
3. Clique "Sincronizar Tempos"
4. Para cada linha:
   - Clique Play
   - Quando a linha começar, clique "⏱️ Marcar"
5. Pronto! Letras sincronizadas

### Limpar Tudo
1. Menu → "Limpar Tudo"
2. Confirmação → Clique "Sim"
⚠️ Não pode ser desfeito!

## 💡 Dicas Rápidas

| Dica | Como Fazer |
|------|-----------|
| Pular para posição | Toque na barra de progresso |
| Reproduzir em 1.5x | Velocidade → 1.5x (ótimo para podcasts) |
| Ver próximas linhas | Letras em cascata aparecem automaticamente |
| Saber quantas músicas | Menu → Veja contagem no topo |
| Voltar ao tempo marcado | Letras → Clique "↩️ Voltar" |

## 🆘 Problemas Rápidos

| Problema | Solução |
|----------|---------|
| App não abre | Reinicie o dispositivo |
| Música não toca | Verifique se é MP3/WAV/FLAC |
| Metadados não aparecem | Edite manualmente (futuro) |
| Letras não sincronizam | Verifique se cada linha está separada |
| Botões não respondem | Feche e abra o app novamente |
